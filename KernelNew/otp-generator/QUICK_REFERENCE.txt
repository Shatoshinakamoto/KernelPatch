┌──────────────────────────────────────────────────────────────────────────┐
│ BASIC COMMANDS                                                           │
└──────────────────────────────────────────────────────────────────────────┘

  Generate New OTP:
    ./otp -g account@service.com -i ServiceName -m

  Show Current Code:
    ./otp -l account@service.com.otp -s

  Watch Mode (Live Updates):
    ./otp -l account@service.com.otp -w

  Verify Code:
    ./otp -l account@service.com.otp -v 123456

  Show Manual Key:
    ./otp -l account@service.com.otp -m

┌──────────────────────────────────────────────────────────────────────────┐
│ COMMAND-LINE OPTIONS                                                     │
└──────────────────────────────────────────────────────────────────────────┘

  -g, --generate <name>     Generate new OTP secret
  -i, --issuer <issuer>     Set issuer name (default: OTPApp)
  -l, --load <file>         Load existing OTP from file
  -s, --show                Display current OTP code
  -v, --verify <code>       Verify an OTP code
  -q, --qr <file>           Save QR code info to file
  -d, --display             Display QR code information
  -m, --manual              Show manual entry key (Base32)
  -w, --watch               Watch mode (continuous display)
  -h, --help                Show help message

┌──────────────────────────────────────────────────────────────────────────┐
│ SETUP WORKFLOW                                                           │
└──────────────────────────────────────────────────────────────────────────┘

  1. Generate Secret:
     $ ./otp -g myemail@gmail.com -i Google -m
     [Displays manual entry key and saves encrypted file]

  2. Add to Authenticator App:
     - Open Google/Microsoft Authenticator
     - Tap "+" → "Enter a setup key"
     - Enter the manual key displayed above

  3. Verify It Works:
     $ ./otp -l myemail@gmail.com.otp -v [code-from-app]
     ✓ Code is VALID

  4. Daily Use:
     $ ./otp -l myemail@gmail.com.otp -s
     Current OTP Code: 123456

┌──────────────────────────────────────────────────────────────────────────┐
│ SECURITY FEATURES                                                        │
└──────────────────────────────────────────────────────────────────────────┘

  • Triple-Layer AES-256-CBC Encryption
  • PBKDF2 with 100,000 iterations per layer
  • Unique salts and IVs for each layer
  • Cryptographically secure random generation
  • Secure memory wiping (volatile)
  • No plaintext secrets on disk
  • Password-protected file storage

┌──────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                          │
└──────────────────────────────────────────────────────────────────────────┘

  Codes Don't Match:
    • Check system time: date
    • Sync time: sudo ntpdate pool.ntp.org

  Build Failed:
    • Install: make g++ libssl-dev
    • Run: make

  Password Forgotten:
    • Cannot recover (by design)
    • Use backup of manual entry key

┌──────────────────────────────────────────────────────────────────────────┐
│ BEST PRACTICES                                                           │
└──────────────────────────────────────────────────────────────────────────┘

  ✓ Use strong, unique passwords (12+ characters)
  ✓ Backup .otp files securely
  ✓ Store manual keys separately
  ✓ Test codes before relying on them
  ✓ Keep system clock synchronized
  ✓ Use password manager for passwords

  ✗ Don't store passwords in scripts
  ✗ Don't share .otp files or passwords
  ✗ Don't use same password for multiple OTP files
  ✗ Don't leave terminal showing codes
